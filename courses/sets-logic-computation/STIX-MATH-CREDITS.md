# গাণিতিক ফন্টের স্বীকৃতি

গণিতের ছয়টি Type 1 ফন্টে STIX Two Math 2.12 b168-এর অক্ষররেখা ব্যবহৃত হয়েছে। মূল ফন্টের স্বত্ব [STIX Fonts Project Authors](https://github.com/stipub/stixfonts)-এর। OpenAI Codex মারাঠি *সেট, যুক্তি, গণনা* সংস্করণের জন্য এই অক্ষররেখাগুলি থেকে Type 1 ফন্ট তৈরি করেছে। সেই ফন্টগুলির পাঁচটি এখানে অক্ষত রাখা হয়েছে। বাংলা সংস্করণের বড় বাঁ দিকের বন্ধনীর রেখাটি একই STIX উৎস থেকে OpenAI Codex — GPT-6.1 Sol (Ultra) তৈরি করেছে। গাণিতিক অক্ষরের স্থান ও মাপ নির্ধারণে TeX বিতরণের NewTX মাপের ফাইল ব্যবহৃত হয়।

এই ছয়টি Type 1 ফন্ট [SIL Open Font License 1.1](font-notices/STIX-Two-Math-OFL.txt)-এর অধীনে। মূল স্বত্বের বিবৃতি ও সম্পূর্ণ লাইসেন্স ওই ফাইলে আছে।
