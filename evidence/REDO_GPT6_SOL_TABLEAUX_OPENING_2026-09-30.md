# মোডাল ট্যাবলোর সূচনা ও K-বিধি: নতুন পুনঃপরীক্ষা

OLP-0460–0463-এর প্রতিটি ইংরেজি ও বাংলা অনুচ্ছেদ, পূর্বসূচি, বিধি, চিত্রিত প্রমাণ, অনুশীলন এবং সংশোধন ২০২৬-০৯-৩০-এ OpenAI Codex — GPT-6.1 Sol, Ultra effort — নতুন করে তুলেছে। স্বাধীন মানব-পর্যালোচনা হয়নি। এই চার এককের বর্তমান hash নথিতে বাঁধা; বিশুদ্ধতা ও অধ্যায়ের অবশিষ্ট ছয় একক এই batch-এর অন্তর্ভুক্ত নয়।

একই দিনে আগের পর্বে সত্যিই পড়া P008/P009 বচন ও সংযোজক, P013 সম্পর্ক, P017 প্রমাণ-গদ্য এবং P018 অপেক্ষকের ক্ষেত্রের রীতি এখানে ব্যবহৃত। পূর্বসূচিযুক্ত ট্যাবলো ও নতুন/ব্যবহৃত উত্তরসূরি-পূর্বসূচির পূর্ণ ভারতীয় বাংলা পদের প্রত্যক্ষ সাক্ষ্য দাবি নেই; মূল বিধি ও নির্দিষ্ট ব্যবহার অর্থ নিয়ন্ত্রণ করে। P017-এর ত্রুটিপূর্ণ প্রদর্শিত সূত্র গণিতের ভিত্তি নয়। এটি পরবর্তী পুনঃপরীক্ষায় প্রকৃত পূর্বপাঠের ব্যবহার; পুরোনো রচনার সময় নতুন canon retrieval-এর দাবি নয়।

| একক | ফল |
|---|---|
| OLP-0460 | অধ্যায়, নয়টি আমদানি ও উৎসের খসড়া-সম্পাদকীয় মন্তব্য যথার্থ। |
| OLP-0461 | চিহ্নিত সূত্র, বদ্ধতা, সসীম পূর্বপক্ষ, অশূন্য ধনাত্মক অনুক্রম ও একই স্থানে অনুমিতির অর্থ যথার্থ। শেষ অনুচ্ছেদে চিহ্নিত সত্যমান পূরণ বলা হয়েছে; False-চিহ্নিত মূল সূত্র সত্য হওয়া দাবি নয়। |
| OLP-0462 | আট বচনমূলক ও চার মোডাল বিধি, শাখা-সাপেক্ষ নতুন/ব্যবহৃত পূর্বসূচি এবং একই পূর্বসূচিতে বদ্ধতা যথার্থ। BN-SRC-371 সঠিক; BN-SRC-727-তে বাদ পড়া False-negation বিধির নির্দেশ। BN-SRC-728-তে পদ্ধতির পরিচয়। |
| OLP-0463 | দুই প্রকৃত বদ্ধ ট্যাবলোর সব ২০টি node, শাখা, বিধি-নির্দেশ ও বদ্ধতা যথার্থ; চার অনুশীলনের সাধারণ প্রমাণ তুলিত। |

চিহ্নিত সূত্রের True বা False চিহ্ন মূল সূত্রের জগৎ-সাপেক্ষ সত্যমান নির্ধারণ করে। কোনো শাখায় শুধু একই সূত্রের দুই চিহ্ন যথেষ্ট নয়; পূর্বসূচিও একই হতে হবে। ভিন্ন জগতে একটি সূত্র সত্য ও মিথ্যা হওয়া সঙ্গত। সসীম পূর্বপক্ষ শূন্যও হতে পারে; তখন কেবল সিদ্ধান্তের False-অনুমিতি থাকে। সাধারণ বচনমূলক বিধির পরে মোডাল বিধি যোগ হয়; উত্তরসূরি-পূর্বসূচি তাৎক্ষণিক অভিগম্যতার নাম।

True Box এবং False Diamond সব ইতিমধ্যে ব্যবহৃত তাৎক্ষণিক উত্তরসূরিতে প্রযোজ্য। False Box এবং True Diamond একটি নতুন পূর্বসূচিতে সাক্ষী তৈরি করে। নতুনত্ব একই শাখার নামের জন্য; দুটি ভিন্ন পূর্বসূচির নামাঙ্কিত প্রকৃত জগৎ ভিন্ন হতে হবে, এমন শর্ত নেই। নতুন সাক্ষীর মানচিত্র আলাদাভাবে বেছে নেওয়ার স্বাধীনতা দরকার। সব অনুমিতি একই পূর্বসূচিতে শুরু হওয়ায় এটি স্থানীয় অনুসিদ্ধান্ত।

বচনমূলক সারণির প্রতিটি বিধিতে চিহ্নিত মূল সূত্রের সত্যমান পূর্ণ হলে অন্তত একটি সিদ্ধান্ত-শাখা পূর্ণ হয়। True conjunction ও False disjunction-এ একই শাখায় দুই সিদ্ধান্ত; False conjunction ও True disjunction-এ দুই বিকল্প শাখা। True conditional-এ False antecedent বা True consequent; False conditional-এ True antecedent ও False consequent। নঞর্থক সূত্রে চিহ্ন উলটে যায়। একই পূর্বসূচি সব ক্ষেত্রে রক্ষিত।

প্রথম তিনটি নিষিদ্ধ উদাহরণে সর্বজনীন মোডাল বিধি কোনো আগে ব্যবহার না হওয়া উত্তরসূরি বানাচ্ছে। উত্তরসূরিহীন এক-জগতের মডেলে Box A সত্য অথচ Diamond A মিথ্যা, তাই এই অবাধ বিধিতে তৈরি বদ্ধ ট্যাবলো বিশুদ্ধতার বিরোধী। পরের তিনটিতে সাক্ষীর নতুন পূর্বসূচি দরকার, অথচ আগে ব্যবহৃতটি নেওয়া হয়েছে। দুই উত্তরসূরির একটিতে A সত্য ও অন্যটিতে মিথ্যা হলে Diamond A সত্য এবং Box A মিথ্যা; পৃথক সাক্ষীকে জোর করে একই পূর্বসূচিতে বসানো যায় না। দুই মৌলিক অপারেটর এবং এক-অপারেটরের দ্বৈত সংজ্ঞার সব ছয় শাখা তুলিত।

BN-SRC-371-তে False Box থেকে False A দেওয়া সঠিক। আর প্রথম নিষিদ্ধ উদাহরণের শুধু Diamond মৌলিক শাখায় False not A থেকে True A-র সিদ্ধান্তে True-negation বিধি লেখা ছিল। BN-SRC-727-তে সেটি False-negation হয়েছে। এই উদাহরণে একমাত্র অভিপ্রেত ভুল নতুন পূর্বসূচিতে সর্বজনীন মোডাল বিধির ব্যবহার; অন্য সব বিধি-প্রয়োগ যথার্থ হওয়া চাই। BN-SRC-728-তে অধ্যায় ও সারণির পরিচয়ে K পদ্ধতির চিহ্ন ব্যবহার করা হয়েছে; শুধু K স্বতঃসিদ্ধের ট্যাবলো নয়।

প্রথম সঠিক প্রমাণে সিদ্ধান্তের False-শর্তমূলক সূত্র থেকে দুই True Box এবং একটি False Box-conjunction পাওয়া যায়। False Box নতুন উত্তরসূরিতে False conjunction দেয়; দুই বিকল্পে যথাক্রমে False A ও False B। ইতিমধ্যে ব্যবহৃত সেই পূর্বসূচিতে সংশ্লিষ্ট True Box থেকে True A বা True B আসায় দুই শাখাই বদ্ধ। দ্বিতীয় প্রমাণে True Diamond-disjunction একটি নতুন পূর্বসূচিতে True disjunction দেয়; False Diamond A ও False Diamond B সেখানে যথাক্রমে False A ও False B দেয়। বিযোজনের দুই বিকল্পে True A বা True B-র সঙ্গে বিরোধে দুই শাখাই বদ্ধ। দুই প্রমাণে একই পূর্বসূচি শাখা ভেদে পুনরায় ব্যবহার করা কোনো সমস্যা নয়; নতুনত্ব শাখা-সাপেক্ষ।

চার অনুশীলনের সাধারণ প্রমাণও একই নিয়মে চলে। প্রথমটিতে False Box-conditional-এর নতুন সাক্ষীতে True p ও False q, অথচ True Box not p থেকে False p; শাখা বদ্ধ। দ্বিতীয়টিতে False Box-disjunction-এর নতুন সাক্ষীতে False p ও False q; True Box p বা True Box q-এর দুই শাখায় যথাক্রমে True p বা True q-তে বিরোধ। তৃতীয়টিতে True Diamond p-র নতুন সাক্ষীতে True p; False Diamond-disjunction থেকে ওই ব্যবহৃত সাক্ষীতে False p-তে বিরোধ। চতুর্থটিতে False Box p-র নতুন সাক্ষীতে False p; True Box-conjunction থেকে সেখানে True p ও True q, ফলে বিরোধ।

প্রকৃত সারণির ৩২টি Boolean case পাস। ছয় নিষিদ্ধ ট্যাবলোর ৩২টি node-এ প্রত্যেকটিতে ঠিক একটি অভিপ্রেত পূর্বসূচি-বিধি লঙ্ঘন এবং বাকি চিহ্ন/সূত্র/নির্দেশ ঠিক। দুই সঠিক ট্যাবলোর ২০টি node-এ কোনো লঙ্ঘন নেই এবং চার leaf যথার্থভাবে বদ্ধ। মৃতপ্রান্ত ও মিশ্র উত্তরসূরির প্রকৃত প্রতিমডেল এবং চার অনুশীলনের সর্বোচ্চ দুই-জগতের পরীক্ষা পাস। সীমিত মডেল-গণনা সাধারণ প্রমাণের বিকল্প নয়। বর্তমান ৭২২-এককের গঠন-পরীক্ষা পাস; বর্তমান পাঠকের দৃশ্যগত পরীক্ষা ও প্রকাশনা বাকি।
