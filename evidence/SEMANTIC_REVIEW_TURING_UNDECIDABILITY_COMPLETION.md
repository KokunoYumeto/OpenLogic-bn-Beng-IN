## Unit review

### OLP-0270 — Representing Turing machines

The language keeps separate binary predicates for machine state/head position and tape-symbol content, together with zero, successor and order symbols that name tape squares and computation instants. Every natural number has a numeral, and the same numeric domain supports both spatial and temporal coordinates. The definition of the language preserves the intended readings of `Q_q(m,n)` and `S_sigma(m,n)` and the source distinction between the object language and the metalanguage used to describe a particular machine and input.

The sentence package `T(M,w)` retains all four components. The arithmetic-order axioms make the displayed numerals distinct and order them. The initial-configuration axioms put the head in the initial state on square 1, reproduce every input symbol and fill the unused right-hand tape with blanks. The transition axioms reproduce each defined right, left or stay move, and the frame formula preserves every tape square other than the square just written. The halting sentence `E(M,w)` remains the disjunction asserting that some square, time, state and scanned symbol realize a pair on which the transition function is undefined. Reverse paraphrase: a finite first-order theory does not execute the machine; it constrains every interpreted time slice so that any model must contain the locally correct initial tape and successor configurations.

BN-SRC-178 changes the grammatical classification of `A(x,y)` and the related open expressions from sentences to formulas, because `x` and `y` remain free until numerals or bound variables replace them. BN-SRC-179 repairs the first left-move branch: the machine writes on the old head square `x'`, so `A(x',y)` must exclude that square from the preservation condition rather than excluding the new head square `x`.

### OLP-0271 — Verification of the representation

The forward direction is constructive. `C(M,w,n)` is the complete finite description of the actual configuration after `n` steps, extending through the furthest initially nonblank or visited square and asserting blanks to its right. A halting configuration entails `E(M,w)` because its state/symbol pair appears in the finite halting disjunction. Induction derives `C(M,w,0)` from the initial axioms and derives each successor configuration from the applicable transition axiom plus the frame condition. The induction includes the first halting configuration: the required hypothesis is that the machine has not halted before step `n`, rather than that it has not halted after step `n`. Consequently, when a run first halts at time `k`, `T(M,w)` entails `C(M,w,k)`, which entails `E(M,w)`, and the implication from `T` to `E` is valid.

The reverse direction builds the canonical structure over the natural numbers. Zero, successor and order receive their standard interpretations; each indexed state and tape predicate is interpreted from the actual run of `M` on `w`. If the run never halts, every required transition exists, so this structure satisfies `T(M,w)` while the halting disjunction is false. Therefore validity of `T(M,w) -> E(M,w)` forces the actual run to halt. Reverse paraphrase: a nonhalting computation itself supplies a countermodel, so a valid implication cannot correspond to a nonhalting machine-input pair.

BN-SRC-180 restores the missing marker on `!T(M,w)` in the forward conclusion. BN-SRC-181 replaces an undefined prose machine `T` with the governing machine `M`. BN-SRC-182 keeps the selected state/symbol pair in the halting lemma's antecedent, restores the predicate marker and binds the primed alternatives inside the disjunction. BN-SRC-183 includes the first halting configuration in the induction's scope, and BN-SRC-184 includes the missing zero-to-one induction step. BN-SRC-185 restores the object-language marker before the written-symbol predicate. BN-SRC-186 repairs both the general and instantiated left-move frame formulas. BN-SRC-187 replaces bare metanatural names by numeral terms in the symbol-persistence exercise. BN-SRC-197 removes an unmatched closing parenthesis after the final derivation exercise.

### OLP-0272 — The decision problem is unsolvable

Assuming a total validity-deciding machine `D`, an effective encoder `E` transforms a machine index `e` and input `w` into the sentence `T(M_e,w) -> E(M_e,w)`. The combined machine first performs that encoding and then runs `D`. By the two verification lemmas, it outputs one exactly when `M_e` halts on `w`, thereby deciding the impossible halting problem. The reduction direction is preserved throughout: a validity decider would yield a halting decider.

Satisfiability is also undecidable because a hypothetical satisfiability decider can be run on the negation of the input sentence and its binary answer reversed. The final theorem retains the weaker positive result: first-order validity is semidecidable. A machine effectively enumerates all derivations and halts with one when it finds a derivation of the input; soundness makes every such positive answer correct and completeness guarantees eventual discovery for every valid input. Reverse paraphrase: proof search recognizes valid sentences, but an invalid sentence can leave the search running forever, so enumeration does not supply a total decision procedure.

BN-SRC-188 replaces all three frozen `E concat D` expressions with the previously defined hooked-machine notation `E frown D`; string concatenation remains a different operation. BN-SRC-189 restores the missing marker on the first occurrence of the sentence metavariable `!B` in the satisfiability reduction.

### OLP-0273 — Trakhtenbrot's theorem

The opening example shows why the original theory is insufficient for finite satisfiability: a nonhalting one-state machine with a stay transition can be represented by a finite cyclic interpretation in which all computation times collapse. The strengthened theory `T'(M,w)` adds a predicate `B` to each transition consequent so that every successor time is strictly beyond every earlier time. This freshness condition blocks cyclic reuse of time points.

If `M` halts after `k` steps, the finite-model construction takes a domain large enough for every represented time, input position and visited square, interprets successor only along the needed finite initial segment, and interprets the machine predicates from the finite run. The bound is `max(k+1,len(w))`, which includes a possible head position at square `k+1` and leaves the last freshness condition compatible with the strict order. Conversely, if a model of `T'(M,w)` and `E(M,w)` existed for a nonhalting run, verification would yield `B(n)` for every positive computation time. The order axioms would then force infinitely many distinct numeral values, contradicting finiteness. Reverse paraphrase: the added predicate converts each genuine computation step into a new ordered domain element, so finite models encode exactly the runs that stop after finitely many steps.

Trakhtenbrot's theorem follows by reduction from halting: a finite-satisfiability decider applied to the effectively constructed conjunction would decide whether `M` halts on `w`. The corollary retains the finite-validity consequence. A sound and complete derivation system for truth in every finite structure, together with semidecidability of finite satisfiability, would produce a decision procedure that the theorem excludes.

BN-SRC-190 extends both occurrences of the finite bound to `k+1`. BN-SRC-191 restores the sole state `q_0` as the exercise transition target and keeps both successor values in the structure `M''`. BN-SRC-192 repairs the left-move frame square and supplies its missing freshness conjunct. BN-SRC-193 restores the marker on the halting sentence in the verification claim. BN-SRC-194 makes the exercise ask for the strengthened theory and the marked halting sentence. BN-SRC-195 restores `T'` in the contrapositive assumption. BN-SRC-196 limits the freshness conclusion to positive times whose configurations exist, avoiding the unsupported `B(0)` claim while retaining infinitely many distinct times for a nonhalting run.
